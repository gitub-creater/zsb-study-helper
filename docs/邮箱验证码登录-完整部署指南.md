# 邮箱验证码登录系统 - 部署指南

## 📋 已完成的修改

### 1. 数据库层 ✅
- **新增表**: \mail_verification_codes\ (存储验证码)
- **新增列**: \pp_users.email\ (用户邮箱)
- **迁移文件**: \mail-verification-migration.sql\

### 2. API 端点 ✅
- **发送验证码**: \/api/auth/send-code\ (POST)
  - 生成 6 位随机验证码
  - 10 分钟有效期
  - 60 秒内同一邮箱限制 1 次
  - 通过 Resend 发送邮件

- **验证登录**: \/api/auth/verify-code\ (POST)
  - 验证邮箱和验证码
  - 自动注册新用户或登录现有用户
  - 返回会话 token

### 3. 前端服务层 ✅
- **新增函数** (\src/services/cloud.ts\):
  - \sendVerificationCode(email)\: 发送验证码
  - \loginWithVerificationCode(email, code)\: 验证码登录

### 4. 前端页面 ✅
- **完全重写** \src/pages/LoginPage.tsx\:
  - ❌ 移除账号密码登录
  - ✅ 新增邮箱验证码登录
  - ✅ 自动识别新用户并注册
  - ✅ 保留游客快速体验功能
  - ✅ 倒计时防重复发送

### 第二步: 配置 Resend 邮件服务

#### 2.1 注册 Resend 账号
1. 访问 https://resend.com
2. 注册免费账号 (每月 100 封免费邮件)
3. 验证你的邮箱

#### 2.2 获取 API Key
1. 进入 Dashboard → **API Keys**
2. 点击 **Create API Key**
3. 名称填写: \zsb-study-helper-production\
4. 权限选择: **Sending access**
5. 复制生成的 API Key (以 \e_\ 开头)

#### 2.3 配置发件域名 (推荐)
**选项 A: 使用自己的域名** (专业，送达率高)
1. 在 Resend Dashboard → **Domains**
2. 点击 **Add Domain**
3. 输入你的域名 (如 \mail.yourdomain.com\)
4. 按提示添加 DNS 记录 (SPF, DKIM, DMARC)
5. 等待验证通过 (通常 5-30 分钟)
6. 发件地址使用: \
oreply@mail.yourdomain.com\

**选项 B: 使用 Resend 提供的测试域名** (仅限测试)
- 免费账号可使用 \onboarding@resend.dev\
- 只能发送到你验证过的邮箱地址
- 不适合生产环境

---

### 第三步: 配置 Vercel 环境变量

1. 访问 Vercel Dashboard
2. 选择你的项目 \zsb-study-helper\
3. 进入 **Settings → Environment Variables**
4. 添加以下变量:

\\\ash
# Resend API Key (必需)
RESEND_API_KEY=re_your_actual_api_key_here

# 发件邮箱 (必需)
EMAIL_FROM=noreply@mail.yourdomain.com

# 发件人名称 (可选)
EMAIL_FROM_NAME=专升本学习助手
\\\

5. **Environment**: 选择 \Production\, \Preview\, 和 \Development\ 全部勾选
6. 点击 **Save**

### 第五步: 配置自定义域名 (解决国内访问问题)

#### 为什么需要自定义域名?
- ❌ \*.vercel.app\ 在国内被墙，无法访问
- ✅ 自己的备案域名可以正常访问

#### 5.1 准备域名
1. 购买域名 (阿里云、腾讯云等)
2. **完成 ICP 备案** (国内访问必需)
3. 添加域名解析

#### 5.2 在 Vercel 添加域名
1. Vercel Dashboard → 你的项目
2. **Settings → Domains**
3. 点击 **Add**
4. 输入你的域名 (如 \zsb.yourdomain.com\)
5. 选择 **Add**

#### 5.3 配置 DNS 记录
在你的域名服务商后台添加:

**CNAME 记录**:
\\\
类型: CNAME
主机记录: zsb (或你想要的子域名)
记录值: cname.vercel-dns.com
TTL: 600
\\\

#### 5.4 等待生效
- DNS 生效时间: 5 分钟 - 24 小时
- Vercel 会自动配置 HTTPS 证书
- 验证: 访问 \https://zsb.yourdomain.com\

#### 5.5 更新前端配置
修改 \.env.production\:
\\\ash
VITE_CLOUD_API_URL=https://zsb.yourdomain.com
\\\

重新部署:
\\\powershell
git add .env.production
git commit -m "chore: 更新为自定义域名"
git push
\\\

## 🔧 故障排查

### 问题 1: 收不到验证码邮件
**可能原因**:
1. 邮件被拦截到垃圾箱 → 检查垃圾邮件文件夹
2. Resend API Key 配置错误 → 检查 Vercel 环境变量
3. 发件域名未验证 → 检查 Resend 域名状态
4. 邮箱地址拼写错误 → 重新输入

**调试步骤**:
\\\powershell
# 查看 Vercel 函数日志
vercel logs zsb-study-helper --follow

# 检查 Resend 发送记录
# 访问 https://resend.com/emails
\\\

### 问题 2: API 返回 404
**可能原因**:
- API 文件未正确部署到 Vercel
- \ercel.json\ 配置问题

**解决方案**:
\\\powershell
# 重新部署
vercel --prod --force

# 验证 API 路由
vercel inspect zsb-study-helper.vercel.app
\\\

### 问题 3: 数据库错误
**可能原因**:
- 迁移未执行
- Supabase 环境变量错误

**解决方案**:
\\\sql
-- 在 Supabase SQL Editor 执行
SELECT EXISTS (
  SELECT FROM information_schema.tables 
  WHERE table_name = 'email_verification_codes'
);
-- 返回 true 说明表已创建

SELECT EXISTS (
  SELECT FROM information_schema.columns 
  WHERE table_name = 'app_users' AND column_name = 'email'
);
-- 返回 true 说明 email 列已添加
\\\

### 问题 4: 国内无法访问
**解决方案**:
- 必须配置自定义备案域名
- \*.vercel.app\ 域名在国内被墙，无解
