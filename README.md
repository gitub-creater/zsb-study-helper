# 专升本学习助手 · 知识校园

山东专升本备考工具(非宣传站):可爱 2D 校园冒险游戏风,学习闭环 = 诊断薄弱点 → 生成计划 → 练习 → 分析错误 → 错题本 → 间隔复习 → 掌握度 → 调整计划。

## 运行

```bash
npm install
npm run dev        # 开发: http://localhost:5173(手机同网段可访问)
npm run build      # 类型检查 + 构建
npm run test       # 单元测试(25 项:间隔复习/掌握度/计划/判分/CSV/等级)
npm run preview    # 预览构建产物
```

同一套响应式代码覆盖电脑端(左侧导航)、手机端(底部导航 + 更多菜单)与平板。默认可离线使用本机存储；配置 Supabase + Vercel 后，账号和学习记录会在网页、手机、电脑端同步，断网时仍可继续学习。部署步骤见 [docs/CLOUD_SYNC.md](docs/CLOUD_SYNC.md)。

## 考试类别体系(依据官方文件)

| 类别 | 学科门类 | 高数科目 | 科目组合 |
|---|---|---|---|
| 高教一类 | 理学 · 工学 | 高等数学Ⅰ | 语文 + 高数Ⅰ + 英语/政治(二选一) + 计算机 |
| 高教二类 | 经济 · 农学 · 医学 · 管理学 | 高等数学Ⅱ | 同上(高数Ⅱ) |
| 高教三类 | 哲学 · 法学 · 教育学 · 文学 · 历史学 · 艺术学 | 高等数学Ⅲ | 同上(高数Ⅲ) |

- 首次引导与「设置 → 备考信息」中选择类别与公共课;首页、知识校园、计划、薄弱点推荐都会随类别自动过滤(可切换"显示全部")。
- 高数Ⅰ/Ⅱ/Ⅲ 为三个独立科目,各自章节深度不同(Ⅱ 无空间解析几何与无穷级数;Ⅲ 重基础);差异对比与官方依据见「考试资料」页。
- 资料来源(名称/机构/日期/链接/核验状态)集中展示在「考试资料」页,检索于 2026-08-28;政策每年可能变化,以[山东省教育招生考试院](https://www.sdzk.cn/NewsInfo.aspx?NewsID=7081)当年发布为准,未逐条核验处均标注"待核实"。

## 内容与题库

- **内容包与代码分离**:`public/data/seed.json`(基础示例)+ `public/data/catalog.json` / `catalog-questions.json`(类别内容包:语文、高数Ⅰ/Ⅱ/Ⅲ、政治、英语/计算机扩展,共 9 科 33 章 76+ 知识点、63+ 题,数学含 LaTeX 公式)。
- **知识点详情**:列表管理中点击知识点名称 → 概念/公式/方法/题型/例题/易错点/前置后续知识/关联题目/笔记/来源。
- **题库**:按科目/章节/知识点/题型/难度/年份/来源/关键词筛选;顺序/随机/薄弱强化/限时练习;真题、高频、标签、适用类别标注;题目题干与解析支持 LaTeX。
- **CSV 批量导入导出**:题库页「导入模板」下载模板 → 填写 → 「导入 CSV」预览校验(必填/答案范围/重名匹配/重复题)→ 确认导入;「导出 CSV」可随时带出全部或筛选结果。

## 数据更新流程(年度大纲变化时)

1. 编辑 `public/data/catalog*.json`(新增科目/章节/知识点/题目,或提升 `meta.version`);
2. 同时把 `src/lib/seed.ts` 中 `CATALOG_VERSION` 递增;
3. 用户重新打开应用即自动幂等合并——**只新增、不删除、不覆盖**,历史学习记录不受影响;旧内容可在知识校园中手动删除。

## 架构要点

- **技术**:Vite + React 18 + TypeScript + 手写 CSS 设计系统 + KaTeX(本地公式渲染,断网可用)。
- **状态**:`src/store/store.tsx` 单一 reducer + 本机防抖持久化 + 删除撤销 + 云端快照同步;内容包合并为幂等操作。
- **云端**:`api/` Vercel Serverless Functions + Supabase PostgreSQL。服务密钥仅存 Vercel 环境变量，账号密码用 scrypt 加盐哈希，浏览器仅保存过期会话令牌。
- **核心算法**(`src/lib/`):间隔复习(1→3→7→14→30 可调,答错回退、最高档连对 2 次归档)、掌握度(<3 次显示数据不足)、计划生成(到期错题优先→类别范围内新知点→巩固练习→每 7 天小测)、经验防刷上限。
- **服务解耦**:`src/services/{ai,search,tts}.ts` 为第三/四阶段预留接口,密钥不进前端,失败不影响本地功能。
- **数据模型**:见 [docs/DATABASE_DESIGN.md](docs/DATABASE_DESIGN.md)(实体映射与多对多设计)。
