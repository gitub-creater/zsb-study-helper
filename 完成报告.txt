## 📋 接下来需要做的

### 必须完成 (才能正常使用)

1. **执行数据库迁移** ⭐ 最重要
   - 打开 Supabase Dashboard
   - SQL Editor → 运行 email-verification-migration.sql
   - 验证 email_verification_codes 表已创建

2. **配置邮件服务**
   - 注册 Resend 账号 (https://resend.com)
   - 获取 API Key
   - 在 Vercel 配置环境变量:
     * RESEND_API_KEY
     * EMAIL_FROM
     * EMAIL_FROM_NAME

3. **部署到 Vercel**
   - 运行: .\deploy-email-verification.ps1
   - 或手动: vercel --prod

4. **测试功能**
   - 运行: .\test-email-verification.ps1
   - 验证验证码发送和登录功能

### 可选完成 (提升体验)

5. **解决国内访问问题** 🌐
   - 绑定自定义域名 (参考: 域名配置指南.md)
   - 推荐使用国内备案域名
   - 或使用 Cloudflare CDN

6. **配置发件域名**
   - 在 Resend 验证自己的域名
   - 避免邮件进入垃圾箱
   - 提升品牌可信度

7. **监控和优化**
   - 查看 Resend 发送统计
   - 监控 Vercel Function 性能
   - 设置告警通知
